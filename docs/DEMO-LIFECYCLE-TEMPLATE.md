- 需求保留最多三级工作分解；7个汇总工作包不再重复创建执行Task，28个叶子工作包才关联真实Task。35个工作项及5个里程碑存为PlanItem。

## 导入与核验

准备现有本地数据库及编译后的API后执行：

```powershell
node scripts/seed-lifecycle-demo.cjs --check
node scripts/seed-lifecycle-demo.cjs
$env:SPM_CHROME_PATH='C:\Program Files\Google\Chrome\Application\chrome.exe'
node scripts/verify-lifecycle-demo.cjs
```

JSON来源：`scripts/fixtures/project-lifecycle-template.json`。日期与状态是可复现的固定快照，不随每次运行随机变化。导入仅允许本地public库，事务内创建；账号名冲突立即拒绝，绝不覆盖已有密码。项目已导入且本地清单匹配时直接退出；清单位置 `.runtime/lifecycle-demo.json`，不会重置用户后续修改。

分支只隔离代码，数据库是当前本机共用数据库；本次通过新增独立项目隔离模拟数据。旧示例项目、账号及用户之前的修改全部保留。导入前后逐行指纹核验原业务记录均保留，Session等临时会话表不参与该对比。
