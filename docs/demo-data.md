更新：推荐使用已重新设计的[校园业务模拟数据](campus-demo-data.md)，命令 `pnpm db:seed:campus`。下文保留旧生命周期模板说明，便于复现原数据。

本分支基于 `feat/ai-seven-pages` 的 `4a9b894`，复用之前 TAPD 截图提取、优化后的生命周期模板，单独提供可重复导入的数据包。业务页面、后端接口、数据库结构不变。

这是一套可复现的初始化数据，不是正在使用的数据库备份。不会导出用户后续试填的记录、真实账户密码、会话、API Key、AI 报告或草稿。

## 导入

在仓库根目录操作，先安装依赖，在后端 `.env` 中设置本地 `DATABASE_URL`。数据库须已启动。脚本仅允许 `localhost` 或 `127.0.0.1`，不会重置数据库。

```powershell
pnpm install --frozen-lockfile
pnpm db:generate
pnpm db:migrate
pnpm --filter @spm/shared build
pnpm --filter @spm/api build
node scripts/seed-lifecycle-demo.cjs --check
pnpm db:seed:demo
```

不依赖已有 `manager` 账户：新项目由 `tpl_pm` 管理。所有示例账户的默认密码为 **`SpmDemo!2026`**。可在首次导入前设置 `DEMO_SEED_PASSWORD`（至少 12 字符）更换示例密码；再次导入不会重置密码。

| 用户名 | 显示名 | 项目角色 |
|---|---|---|
| `tpl_pm` | 林知远 | 项目经理 |
| `tpl_frontend` | 陈思雨 | 开发人员 |
| `tpl_backend` | 周启明 | 开发人员 |
| `tpl_qa` | 赵可欣 | 测试人员 |
| `tpl_ops` | 吴承安 | 开发人员 |
| `tpl_observer` | 未授权访客 | 无项目成员资格，用于越权验证 |

用户名、邮件地址或项目名称冲突时会拒绝导入，避免覆盖现有账户和权限。已带本模板标记的项目会直接跳过，保留后续业务修改。旧版导入的同名项目，如果本地 `.runtime/lifecycle-demo.json` 能确认其来源，也会跳过。不会自动删除或重新生成旧项目。

导入结果 ID 清单写入忽略提交的 `.runtime/lifecycle-demo.json`。此文件供本机定位数据使用，不需要上传。

## 验证记录

执行 `pnpm test:demo-data`，测试会在配置的本地 PostgreSQL 内创建独立测试 schema，运行全部现有增量迁移，完成后仅删除本次测试 schema。不会调用 AI Provider，也不修改 public 业务数据。

2026-10-24 实测通过：

- 模板结构检查：五阶段、35 条工作分解、树无环、日期边界和负责人有效。
- 真实 PostgreSQL 导入：数量、三级需求、跨对象关联、任务状态及历史日期、文档字节、账户密码、项目成员关系正确。
- 二次导入：无重复数据，保留首次导入后的任务修改及无关账户、项目记录。
- 同名非模板项目冲突：导入失败，已有账户和任务保持不变。

本次仅增加数据包和脚本，未修改业务 UI，未重新执行全部浏览器回归。初始化数据不包含预制 AI 结果；页面分析仍需用户手动触发已配置的服务。
