# 用户手册与演示步骤

适用 `v2.0.0-rc.1`。先按根目录 [README](../README.md) 完成数据库迁移、构建、五阶段示例及可选时序场景导入，启动本地 Web / API。全程使用 `http://127.0.0.1:5173/`。

## 账户与权限

`tpl_pm` 演示项目经理；`tpl_frontend` 演示开发成员；`tpl_qa` 演示测试成员；`tpl_observer` 演示非成员。默认演示密码见 README；如果首次导入设置了 `DEMO_SEED_PASSWORD`，使用该密码，重复导入不会重置密码。

系统管理员 `admin` 的密码来自本机 `.env` 的 `SEED_PASSWORD`，可维护系统账户，但不自动获得所有项目数据。项目经理能管理本项目；开发和测试成员的写入范围受项目和本人任务权限约束。角色变化、停用或成员移除可能令原会话请求被拒绝，应按页面提示重新选择项目或登录。

## 主旅程：从需求追踪到成员执行

以下步骤会编辑本地示例数据。固定模板是可重复导入的初始数据，不会在每次导入时恢复你的修改；演示前记录所改对象与原值。

1. 以 `tpl_pm` 登录，在“我的项目”进入“爱管理协同平台建设 · 五阶段示例”。项目概览显示该项目真实需求、任务及成员信息。
2. 进入需求管理，查看需求树、验收标准、故事地图与看板。选择故事打开详情，确认需求和任务关联。经理可编辑；故事状态与任务状态分别维护。
3. 进入项目计划，切换阶段，检查计划项、里程碑和正式甘特。选择“日 / 周 / 月”；编辑日期或拖动计划条，在前后对比确认中取消或保存。保存后重新打开详情核对日期。
4. 进入多视图工作台，默认查看甘特。单击计划项仅聚焦，右侧追踪显示关联对象；完整详情通过明确的详情按钮打开。
5. 点击“双视图联动”，确认左甘特、右成员任务图。分隔条默认 55/45，可拖动或用键盘调整。选择一项有任务关联的计划，展开任务；点击任务或成员观察反向高亮和负责人定位。
6. 打开与关闭追踪覆盖层，观察两侧图面仍保留滚动、缩放和焦点。“仅看关联项”开启后只显示相关对象，关闭后恢复全部对象。
7. 从任务详情调整一个任务的负责人，核对前后预览后保存。成员图与任务详情应同步；关联计划自身的负责人不应被连带修改。
8. 退出经理账户，以该任务的新负责人登录，从“我的任务”打开它。对处于进行中的本人任务更新进度，刷新确认保存；操作记录应能追溯实际变更。
9. 回到经理会话，查看任务图及任务详情的最新状态。另一个浏览器会话保持项目打开时，可观察 SSE 同步；不是自动调用 AI。

验收重点是入口→需求 / 计划关联→分配→成员执行→经理读回，而不是逐页展示静态截图。记录所用对象 ID、改前改后、时间及截图；勿将本手册本身当作本次执行通过的证明。

## 异常与权限旅程

1. 以 `tpl_observer` 登录，确认不能看到示例项目；猜测项目编号不应获得其内容。
2. 以普通成员登录，查看本项目及本人任务，确认没有经理专用的任务改派、计划编辑和 AI 生成权限。页面隐藏按钮不能代替 API 授权；已有 API 测试覆盖越权拒绝。
3. 两个经理会话打开同一对象，先在一处保存，再在另一处提交旧修订号，应提示冲突，不能静默覆盖。请重新读取最新对象后再决定修改。
4. 选择“恢复联调环境访问”等未纳入计划的任务，开启关联过滤，甘特应显示无关联计划空态；不要把它关联到任意计划来掩盖空状态。

授权规则可能用 404 隐藏无权项目的存在性，或对已知成员的越权操作返回 403；不同接口不要求一律相同状态码。

## UML、文档与 AI

- UML：在工作台选择 UML 建模，查看用例图；切到时序图，查看已导入的三个场景。用例和时序场景通过真实故事关系联动；图中的消息是设计描述，不代表程序实时运行轨迹。
- 文档：查看文件夹、上传文件、下载和属性。图片、文本、PDF 等按支持格式预览；Office 文件使用下载后的本地应用打开。
- AI：经理在相应入口手动发起分析或候选生成。未启用供应商时按提示处理，业务功能仍可用。生成→人工编辑→保存草稿→逐项审核→提交，只有最后受授权的提交才写入正式对象。来源过期时重新校验和审核。

## 演示常见问题

| 现象 | 检查方法 |
| --- | --- |
| 页面打不开或 API 失败 | 确认 `pnpm dev`、数据库健康和 5173 / 3000 / 5433 端口；查终端错误 |
| 登录成功但无项目 | 确认示例导入完成并使用 tpl_pm；系统管理员不自动拥有项目 |
| 时序场景为空 | 先导入五阶段示例，再运行 `node scripts/seed-workbench-scenarios.cjs` |
| 看不到任务 | 核对项目、本人任务范围及“仅看关联项”等筛选，不重置数据库 |
| 日期显示逾期 | 示例快照和日期固定，不能将历史日期当成当前项目承诺 |
| AI 不可用 | 检查本机后端配置、授权范围和供应商状态；不要把密钥写入页面 |
| 迁移或文件权限错误 | 保留错误并修复访问权限；不要靠清库或删除组件绕过 |
