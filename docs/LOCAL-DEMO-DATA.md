# 本地 AB 验收数据

2026-10-22 已通过 `node scripts/seed-local-demo.cjs` 写入当前本地 PostgreSQL。该脚本只允许本地数据库，事务提交，重复运行发现同名验收项目后直接退出；不清空旧数据，不修改现有账号密码。

在 http://127.0.0.1:5173/ 登录后，从“我的项目”进入 **爱管理 · AB统一验收项目**（本机项目 ID 2）。创建数据后，已经打开的页面需要刷新一次。

| 账号 | 密码 | 用途 |
| --- | --- | --- |
| manager | 保持原密码 | 验收项目经理，完整编辑 |
| demo_dev | SpmDemo!2026 | 开发成员，有本人任务 |
| demo_dev2 | SpmDemo!2026 | 第二位开发，验证成员分组及重分配 |
| demo_tester | SpmDemo!2026 | 测试成员，有本人任务 |
| demo_pm | SpmDemo!2026 | 其他项目经理，验收项目切换及角色统计 |
| demo_outsider | SpmDemo!2026 | 未加入任何项目，验证无法访问项目数据 |

这些固定密码仅用于用户明确要求的本地验收账号，脚本不是生产自动初始化流程。

数据包含：10条需求（含三级父子结构）、3个产品目标、6个Epic、12个故事、16个Task、4个阶段、12个阶段目标、16个计划工作项与4个里程碑、4个文件夹与5个真实文件、2张用例图。主用例图有参与者、用例、association/include/extend，以及故事关联。第二张空图用于新增编辑练习。

故事、任务覆盖三状态；任务覆盖四优先级、不同负责人、未分配与已归档，含操作记录。需求→故事→任务→计划项全部使用真实关联。计划覆盖待处理/进行中/已完成/暂缓；日期以创建时当前日期为基准，跨越过去、现在与未来，适合甘特图验收。

文档包含验收指南、项目范围说明、故事验收标准、CSV回归清单及可读的多视图联动PNG截图，可直接预览和下载；有三级目录路径，可练习重命名、移动、删除及批量操作。

另外新增两个可访问项目用于卡片/列表、我管理/我参与筛选和切换；一个未授权项目由 demo_pm 管理，manager/demo_dev/demo_tester 不应看到它。

实际核验：主项目五类读取接口返回200；1440×900浏览器依次打开概览、需求、计划、任务、工作台、文档、成员页面，运行异常0；开发和测试账号可读取项目但创建阶段返回403；未加入项目账号访问项目返回404（隐藏项目存在性）。重复运行种子脚本未新增重复项目。此检查验证数据可展示及权限，不替代此前完整业务交互回归。

2026-10-22 系统用户管理接入时另行新增本地系统管理员 demo_admin，密码 SpmDemo!2026；另有禁用状态验收账号 demo_disabled。这两个账号不由前述项目种子脚本创建，且均未自动加入任何项目。manager 保持原项目经理身份。
